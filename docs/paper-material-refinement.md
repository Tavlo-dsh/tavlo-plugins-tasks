# 任务纸张材质与全局主题 0.1.2

本次仅调整 `client.js` 的纸面 CSS，默认 DSH 外观、React 组件、事件处理、菜单/浮层关闭规则、输入焦点、存储与删除回执均未修改。当前任务目录另有独立进行中的 0.2.0 业务工作；此次没有更改其版本号或服务、SQLite、MCP 实现。

浅色使用明亮的浅蓝底板、接近白色的横线纸页、白色任务卡。取消看板全幅纤维、微线网格与工具栏粗纹理，纸张纹理降低强度，文字区域更干净。主要操作与全局绿色交互色一致；任务列使用黄、蓝、绿荧光笔与胶带。

深色使用由暗到亮的底板、横线纸页和任务卡，卡片增加纸边叠层。纹理采用独立 wash token 控制，去掉使纸页和卡片混成一片的统一 soft-light。表单、选择列表和工具栏使用干净的宿主表面色。

所有装饰仍限定在 `body[data-dsh-paper-theme="paper"] .dsh-tasks-root` 下，颜色从 `--dsh-paper-*` 读取。新增材质 token 缺失时回退到既有 token；不开启或不安装主题时继续沿用 DSH 默认样式。任务页没有本地外观开关。

验证命令与真实浏览器截图记录在相邻主题项目的 `docs/palette-refinement-0.1.2.md`。本次运行当前任务回归共 96 项通过，离线 Looseleaf 审查的 60 个文件、两张 PNG 和完整 MIT 许可均匹配固定来源；没有新增复制内容。
