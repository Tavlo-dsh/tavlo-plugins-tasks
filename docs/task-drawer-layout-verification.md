# 新建与任务详情抽屉：验收清单

## 手工验收

1. 打开「新建任务」。依次检查：标题、描述、标签／优先级、截止日期、工作区／模型、任务图片。描述默认可输入，空白时不可预览；粘贴多行 Markdown 后，输入框随内容增高。「预览」在同一位置替换输入框，不影响直接创建；切回「编辑」恢复原文、焦点和选区。关闭再打开，草稿仍在。打开已有任务时，描述默认渲染，清单复选框与正文同排；点「编辑描述」修改，保存后回到阅读状态。
2. 在新建抽屉选一张图，确认显示 `1/10` 和待上传提示。创建后打开详情：字段顺序不变，同一图片显示为已上传，可预览、移除。没有上传原始文件名的数据时显示「图片 1」等编号。
3. 在两种抽屉内设置截止日期。清除按钮只在有值时出现在框内；清除后日期框宽度不变，键盘焦点回到日期触发器。详情里的变更仍需点「保存修改」。
4. 详情中切换「详情／动态」，试用方向键和 Home / End。编辑后关闭应出现放弃确认，未编辑时底部仍是原有启动或会话操作。
5. 浅色、深色各核对一次。桌面约 640 px 抽屉内，成对字段同排；375 px 窄屏下转单列并可独立滚动正文，底部操作一直可达。

## 重新运行回归

在 `tavlo-plugins-tasks` 目录运行：

```powershell
npm test
$env:TASK_DRAWER_LAYOUT_CLIENT = 'built'
node scripts/task-drawer-layout-probe.mjs
```

浏览器探针需要 Chromium、Playwright 和预构建的 DSH Web 前端。工具路径及输出位置可通过[探针脚本](../scripts/task-drawer-layout-probe.mjs)顶部列出的环境变量覆盖。它在独立的浏览器上下文使用合成任务数据，不访问日用 Web profile 或任务存储；本地插件包另由 `npm pack` 构建。
