# Tavlo Light Theme

Clean, crisp light theme matching Tavlo / DeepSeek Harness desktop application.
Pure white backgrounds, subtle border dividers (`#e2e8f0` / `#f1f5f9`), soft neutral text (`#0f172a` primary, `#64748b` secondary), with vibrant semantic status accents (red for alerts/approvals, blue for active execution, amber for blocking/warnings).
